# Перекрёсток: магазины и продукты

Идентификатор в панели и MCP: `perekrestok`. Стартовая витрина: [Перекрёсток](https://www.perekrestok.ru). Источник для проверки принадлежности: [сайт сети или группы](https://www.x5.ru/ru/consumer/).

Перед работой прочитать [общий сценарий браузера](../grocery-prices-browser/references/browser-workflow.md). Для выгрузки использовать [формат наблюдений](../grocery-prices-browser/references/observations.md); для сравнения — [правила соответствия товаров](../grocery-prices-browser/references/matching.md).

Для списка из чата, сохранения количества, выбора предложения и продолжения после входа использовать [общий контракт плана покупок](../grocery-prices-browser/references/shopping-plan.md). Новые команды относятся к подготовленной 0.9.0 и доступны только при наличии в схеме подключённого сервера; прежний браузерный импорт 0.8.0 сохраняется. Подтверждать сохранение по ответу панели, а не по подготовке команды.

## Особенности витрины

Проверить выбранный магазин и режим доставки/самовывоза. Различать цену Х5 Клуба, персональные предложения и обычную цену. Не переносить результаты других сервисов X5 в эту сеть.

В прогоне 2026-10-25 сайт показал «Проблемы со связью. Проверьте настройки интернета и VPN». Сохранён error, а не unsupported_city или not_found.

## Результат

Для исследования магазина вернуть подтверждённые город, публичную точку/зону, режим получения и доступность каталога со ссылкой. Для поиска прочитать до трёх подходящих вариантов на позицию; открыть карточки, если выдачи недостаточно для фасовки, условий или состава. Для сравнения сохранить точный товар и допустимые замены раздельно. Не угадывать наличие по одной лишь отображаемой цене.

Передать наблюдения через `prices_browser_show` с `store="perekrestok"`. Если сеть заблокирована или каталог недоступен, передать `checks` с наблюдаемой причиной. Сбой не означает, что сети нет в городе. При отсутствии инструмента вернуть связанную с источниками таблицу и локальный JSON без персональных данных.

## Проверка сценария

Дата подготовки: 2026-10-25. Фактический браузерный прогон, его город и ограничения указаны в [матрице проверки](../grocery-prices-browser/references/verification.md). Наличие скилла не означает успешный доступ к каталогу; перед каждым сбором перепроверять выбранную локацию и текущий интерфейс.
