# Чижик: магазины и продукты

Идентификатор в панели и MCP: `chizhik`. Стартовая витрина: [Чижик](https://chizhik.club). Источник для проверки принадлежности: [сайт сети или группы](https://www.x5.ru/ru/consumer/).

Перед работой прочитать [общий сценарий браузера](../grocery-prices-browser/references/browser-workflow.md). Для выгрузки использовать [формат наблюдений](../grocery-prices-browser/references/observations.md); для сравнения — [правила соответствия товаров](../grocery-prices-browser/references/matching.md).

## Особенности витрины

Начинать с города и карты магазинов. Проверить, доступен ли поисковый каталог для выбранного магазина. Акционный буклет — advertisement, а не подтверждение наличия. Товары собственных марок сравнивать как замены только при соответствии требованиям.

В прогоне 2026-10-25 стартовая страница потребовала CAPTCHA «Разверните картинку горизонтально». Сохранён captcha, город и товары не проверены. Ссылку проверки защиты не передавать в панель.

## Результат

Для исследования магазина вернуть подтверждённые город, публичную точку/зону, режим получения и доступность каталога со ссылкой. Для поиска прочитать до трёх подходящих вариантов на позицию; открыть карточки, если выдачи недостаточно для фасовки, условий или состава. Для сравнения сохранить точный товар и допустимые замены раздельно. Не угадывать наличие по одной лишь отображаемой цене.

Передать наблюдения через `prices_browser_show` с `store="chizhik"`. Если сеть заблокирована или каталог недоступен, передать `checks` с наблюдаемой причиной. Сбой не означает, что сети нет в городе. При отсутствии инструмента вернуть связанную с источниками таблицу и локальный JSON без персональных данных.

## Проверка сценария

Дата подготовки: 2026-10-25. Фактический браузерный прогон, его город и ограничения указаны в [матрице проверки](../grocery-prices-browser/references/verification.md). Наличие скилла не означает успешный доступ к каталогу; перед каждым сбором перепроверять выбранную локацию и текущий интерфейс.
