# Ашан: магазины и продукты

Идентификатор в панели и MCP: `auchan`. Стартовая витрина: [Ашан](https://www.auchan.ru). Источник для проверки принадлежности: [сайт сети или группы](https://www.auchan.ru).

Перед работой прочитать [общий сценарий браузера](../grocery-prices-browser/references/browser-workflow.md). Для выгрузки использовать [формат наблюдений](../grocery-prices-browser/references/observations.md); для сравнения — [правила соответствия товаров](../grocery-prices-browser/references/matching.md).

## Особенности витрины

До поиска подтвердить город, гипермаркет/склад и доставку или самовывоз. Промокаталог и реальный ассортимент выбранной точки читать отдельно. Фасовку и весовую цену брать из карточки; карту лояльности и скидку за количество указывать в условиях.

В прогоне 2026-10-25: регион → Татарстан → Самовывоз → АШАН Казань (Победы, 91). После «Сохранить» дождаться обновления шапки. Между запросами использовать «Очистить» и проверить фактический текст поля: простая замена ввода может склеить запросы. При нерелевантной выдаче яиц перейти в «Яйцо куриное». Готовая отварная гречка не заменяет крупу; цена яблок за кг не является ценой пакета ~2 кг.

## Результат

Для исследования магазина вернуть подтверждённые город, публичную точку/зону, режим получения и доступность каталога со ссылкой. Для поиска прочитать до трёх подходящих вариантов на позицию; открыть карточки, если выдачи недостаточно для фасовки, условий или состава. Для сравнения сохранить точный товар и допустимые замены раздельно. Не угадывать наличие по одной лишь отображаемой цене.

Передать наблюдения через `prices_browser_show` с `store="auchan"`. Если сеть заблокирована или каталог недоступен, передать `checks` с наблюдаемой причиной. Сбой не означает, что сети нет в городе. При отсутствии инструмента вернуть связанную с источниками таблицу и локальный JSON без персональных данных.

## Проверка сценария

Дата подготовки: 2026-10-25. Фактический браузерный прогон, его город и ограничения указаны в [матрице проверки](../grocery-prices-browser/references/verification.md). Наличие скилла не означает успешный доступ к каталогу; перед каждым сбором перепроверять выбранную локацию и текущий интерфейс.
