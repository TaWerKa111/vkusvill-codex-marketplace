# Исследование магазинов через браузер клиента

Определить продукты, город и выбранные сети из запроса и контекста панели. Город не фиксирован; Казань используется только в историческом тестовом прогоне. Для списка из чата сначала прочитать [контракт плана покупок](references/shopping-plan.md): сохранить исходные количества, получить контекст панели и подтверждение применения. Контракт 0.9.0 подготовлен, но не опубликован; на 0.8.0 использовать только реально объявленные инструменты и поля. Перед маршрутизацией прочитать [реестр возможностей](references/stores.md); машинные идентификаторы и разрешённые домены — в [stores.json](references/stores.json).

## Выбор источников и объём проверки

1. Если пользователь назвал сети, работать в этих границах; выбор пользователя важнее исторической успешности. Не подменять запрошенную сеть другой без явного пояснения. Учитывать выбранные сети панели, если запрос их не переопределяет.
2. В выбранных границах сначала использовать доступный и работающий подключённый источник, если его география и контекст подходят запросу; не считать само наличие инструмента подтверждением текущей работоспособности. `prices_search` документирован для публичного ВкусВилла и Бахетле (Казань, Павлюхина 57, самовывоз), а не для региональных цен всех сетей. Публичные цены ВкусВилла не подтверждают цены по адресу.
3. Если сети не заданы ни в запросе, ни в панели, уточнить охват в существующем чате. Пятёрочка первая в выборе, но не выбрана по умолчанию. Для 0.9.0 всегда задавать `store_ids` при `prices_search`; 5ka + magnit не вызывают каталоги ВкусВилла или Бахетле. Если установленная 0.8.0 не поддерживает фильтр, не вызывать общий поиск для несовместимого охвата.
4. Браузер применять к недостающим данным выбранных сетей по их навыкам. Записи CAPTCHA, error и login_required от 2026-10-25 — история одной сессии, не запрет повторной проверки и не текущий результат. Проверять доступность заново; при актуальном препятствии фиксировать причину без обхода защиты и продолжать остальные выбранные сети.
5. Для `lavka`, `okey`, `dixy`, `monetka` использовать общий сценарий с ID и хостами реестра; отдельного навыка нет. `bahetle` поддерживает только применимый подключённый источник и местный список, без браузерного импорта. Все 17 сетей доступны для списка; импортируемых сетей 16, отдельных навыков 12.

В ответе явно разделить: какие сети и позиции запрошены, какие проверены сейчас, какие дали только справочные сведения, какие заблокированы с причиной и какие не проверялись. Не выдавать непроверенную сеть за `not_found` и не создавать для неё фиктивный check. Частичный результат назвать частичным; цену «самая дешёвая» ограничить сопоставимыми подтверждёнными предложениями в фактическом охвате.

Для поиска использовать подходящий подключённый источник; `prices_search` даёт публичный ВкусВилл и Бахетле Павлюхина 57 в Казани, но не региональные цены всех сетей. Для недостающих сведений применять браузер клиента. Сервер MCP не управляет клиентским браузером самостоятельно.

Собирать результаты по выбранному охвату, отправляя завершённые магазины через `prices_browser_show`; панель объединяет порции. Для нескольких продуктов делать отдельный вызов на каждый запрос `q`. Использовать [формат](references/observations.md) и [сопоставление](references/matching.md). При ограничениях продолжать остальные сети и возвращать точный охват. Не оформлять заказы и не создавать расписания. Сохранить прежние пользовательские списки.

Исторические результаты и ограничения одной сессии: [матрица прогона](references/verification.md). Они не заменяют проверку текущего города, точки, способа получения и наличия.


Выбирать подтверждённый кандидат через `shopping_offer_select` по полной ссылке из контекста панели; не передавать придуманную цену. План магазина не является корзиной на его сайте. Только ВкусВилл поддерживает реальную ссылку/проверяемый перенос через отдельное подтверждение. При блокировке сохранять другие результаты и продолжать только незавершённую сеть через `shopping_research_update` с новой попыткой после действия пользователя.
