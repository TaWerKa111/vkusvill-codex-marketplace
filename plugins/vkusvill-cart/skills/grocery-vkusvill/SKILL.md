# ВкусВилл: магазины и продукты

Идентификатор в панели и MCP: `vv`. Стартовая витрина: [ВкусВилл](https://vkusvill.ru). Источник для проверки принадлежности: [сайт сети или группы](https://vkusvill.ru).

Перед работой прочитать [общий сценарий браузера](../grocery-prices-browser/references/browser-workflow.md). Для выгрузки использовать [формат наблюдений](../grocery-prices-browser/references/observations.md); для сравнения — [правила соответствия товаров](../grocery-prices-browser/references/matching.md).

## Особенности витрины

Сначала использовать доступный products_search для нахождения ID, фасовки и состава. Публичный каталог не подтверждает цену и наличие по адресу: для этого нужен выбранный магазин/зона в клиентском браузере. Любимый продукт и персональные скидки не считать общедоступной ценой; весовой товар не считать упаковкой. Этот скилл не вызывает cart_add или cart_link.

В прогоне 2026-10-25 выбор способа и времени доставки в неавторизованной сессии открыл ввод телефона. Зафиксирован login_required; цены публичного MCP-каталога не доказывают наличие и цену в Казани. Продолжить региональный сбор после входа пользователя и подтверждения зоны.

## Результат

Для исследования магазина вернуть подтверждённые город, публичную точку/зону, режим получения и доступность каталога со ссылкой. Для поиска прочитать до трёх подходящих вариантов на позицию; открыть карточки, если выдачи недостаточно для фасовки, условий или состава. Для сравнения сохранить точный товар и допустимые замены раздельно. Не угадывать наличие по одной лишь отображаемой цене.

Передать наблюдения через `prices_browser_show` с `store="vv"`. Если сеть заблокирована или каталог недоступен, передать `checks` с наблюдаемой причиной. Сбой не означает, что сети нет в городе. При отсутствии инструмента вернуть связанную с источниками таблицу и локальный JSON без персональных данных.

## Проверка сценария

Дата подготовки: 2026-10-25. Фактический браузерный прогон, его город и ограничения указаны в [матрице проверки](../grocery-prices-browser/references/verification.md). Наличие скилла не означает успешный доступ к каталогу; перед каждым сбором перепроверять выбранную локацию и текущий интерфейс.
