# Smart: магазины и продукты

Идентификатор в панели и MCP: `smart`. Стартовая витрина: [Smart](https://smart.swnn.ru). Источник для проверки принадлежности: [сайт сети или группы](https://smart.swnn.ru/about).

Перед работой прочитать [общий сценарий браузера](../grocery-prices-browser/references/browser-workflow.md). Для выгрузки использовать [формат наблюдений](../grocery-prices-browser/references/observations.md); для сравнения — [правила соответствия товаров](../grocery-prices-browser/references/matching.md).

## Особенности витрины

Использовать розничную сеть Smart ООО «Сладкая жизнь плюс», не Smart Pro и не оптовый каталог. Проверить карту магазинов и выбранный город. Искать через видимый «Поиск товара», затем читать карточку; условия по QR-коду приложения и срок акции записывать отдельно. Предложение другого города не подтверждает наличие в Казани.

В прогоне 2026-10-25: нажать город в шапке → Казань; выбранная точка — Оренбургский тракт, 158. Поле «Поиск товара» после фокуса превращается в «Что хотите найти?», затем кнопка «Найти». Дождаться карточек, а не только нового заголовка. Карточки показывают цены, но не подтверждают остаток. Метку «По карте 5шт» сохранять дословно; не угадывать, означает ли число минимум или ограничение акции.

## Результат

Для исследования магазина вернуть подтверждённые город, публичную точку/зону, режим получения и доступность каталога со ссылкой. Для поиска прочитать до трёх подходящих вариантов на позицию; открыть карточки, если выдачи недостаточно для фасовки, условий или состава. Для сравнения сохранить точный товар и допустимые замены раздельно. Не угадывать наличие по одной лишь отображаемой цене.

Передать наблюдения через `prices_browser_show` с `store="smart"`. Если сеть заблокирована или каталог недоступен, передать `checks` с наблюдаемой причиной. Сбой не означает, что сети нет в городе. При отсутствии инструмента вернуть связанную с источниками таблицу и локальный JSON без персональных данных.

## Проверка сценария

Дата подготовки: 2026-10-25. Фактический браузерный прогон, его город и ограничения указаны в [матрице проверки](../grocery-prices-browser/references/verification.md). Наличие скилла не означает успешный доступ к каталогу; перед каждым сбором перепроверять выбранную локацию и текущий интерфейс.
