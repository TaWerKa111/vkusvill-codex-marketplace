# Реестр сетей и границы поддержки

[stores.json](stores.json) — машиночитаемый справочник для маршрутизации навыка и проверок репозитория, а не новый серверный API. Он не изменяет allowlist работающего MCP-сервера, не подключает каталоги и не мигрирует списки. Данные перенесены из существующих навыков, [контракта наблюдений](observations.md), [исторической матрицы](verification.md) и [README](../../../../../README.md); нового живого прогона при создании реестра не было. Список ID/доменов скопирован из контракта до выделения реестра; теперь контракт ссылается сюда, поэтому эта ссылка сама по себе не является независимой проверкой доменов.

## Схема, версия 1

- `schemaVersion`: версия формата этого файла, не версия плагина/сервера.
- `stores`: ровно 12 сетей с документированными wire ID и отдельными навыками. `id` передаётся как `store` без переименований; `skill` — путь относительно каталога `references/`; `officialDomains` — точные имена хостов из контракта, не маски и не разрешение всех поддоменов. URL наблюдений всё равно должен быть HTTPS.
- `capabilities.manualLists`: документирована поддержка пользовательских списков. Это не подтверждение присутствия сети в городе.
- `capabilities.browserWorkflow`: в пакете есть отдельный навык сети. `true` не обещает доступный каталог; `false` у дополнительных сетей означает отсутствие такого навыка, не невозможность работы общим сценарием.
- `capabilities.browserObservationImport`: `true` означает документированный ID и домены импорта; `"unverified"` — контракт для этой сети в репозитории не подтверждён. Это не результат живого вызова сервера.
- `capabilities.connectedCatalog`: `public_catalog` — документирован публичный каталог ВкусВилла; `location_scoped_catalog` — источник Бахетле в Казани, Павлюхина 57, самовывоз; `not_documented` — подключённый каталог в репозитории не описан, а не утверждение об отсутствии API у сети.
- `historicalVerification`: дата, город, краткий результат и ограничения **исторического** браузерного прогона. `catalog_read` означает чтение каталога, `reference_only` — справочные цены с существенными неподтверждёнными условиями. Остальные результаты описывают препятствие в той сессии. Эти значения не являются схемой `checks.status` и не копируются автоматически в новый импорт.
- `additionalNetworks`: отдельно перечисленные в README сети без подтверждённых здесь wire ID и доменов. `id: null` и пустой `officialDomains` намеренны; `supportLevel: list_only` означает только документированную поддержку списков в рамках реестра. Бахетле выделен как `connected_catalog_documented`, потому что README дополнительно описывает `prices_search`, но его ID/домены нельзя вывести из названия сети.
- `documentedPanelStoreCount: 17`: заявление README о справочнике панели. В доступных документах удалось явно сопоставить 12 основных и 4 дополнительных названия; `unresolvedPanelStoreCount: 1` оставляет пробел видимым, не создавая вымышленную сеть/ID. Это не инвентаризация работающего сервера.
- `evidence`: относительные пути к документам-основаниям. Пути во всём JSON разрешаются от каталога этого файла.

## Как выбирать маршрут

1. Границы задаёт запрос пользователя, затем выбранные сети панели. История ошибок не отменяет выбор пользователя.
2. В этих границах сначала проверить доступные подключённые источники и их применимость к городу, точке и способу получения. Для недостающих данных использовать браузер клиента. Не переносить публичную цену в региональный подтверждённый итог.
3. Без выбранных сетей начать с подходящих работающих подключённых источников, назвать фактический охват; если их нет — уточнить сети. Не превращать 12 навыков в обязательный обход 12 сайтов. Полный обход допустим по явному запросу.
4. CAPTCHA, VPN/ошибка связи, требование входа и логистический каталог в прогоне 25 октября 2026 — не постоянные чёрные списки. Повторная проверка разрешена по задаче, но только обычным интерфейсом и без обхода защиты. Текущие ограничения фиксировать с фактическим временем текущей проверки.
5. Для дополнительных сетей не угадывать ни ID, ни официальный домен. До подтверждения контракта импорта использовать чат со ссылками, не `prices_browser_show` с выдуманным `store`. Добавление домена в этот JSON само по себе не разрешает импорт на сервере.

## Что означает частичный результат

Отдельно показать запрошенные сети/позиции, реально проверенные, справочные результаты, текущие препятствия и непроверенную часть. Не создавать `check` для непросмотренной сети и не объявлять отсутствие товара из-за ошибки загрузки. «Самая дешёвая» относится только к сопоставимым подтверждённым предложениям в указанном охвате, а не ко всем 17 сетям панели.

Успешный исторический поиск, наличие навыка и разрешённый домен не подтверждают текущие цены, запасы, акционные условия, доставку или возможность покупки. Эти факты собираются заново по [общему сценарию](browser-workflow.md) и [правилам сопоставления](matching.md).
