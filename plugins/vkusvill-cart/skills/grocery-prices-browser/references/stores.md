# Реестр сетей и границы поддержки

[stores.json](stores.json) — канонический описательный реестр версии 2. Он согласован со справочником приложения и разрешёнными хостами 29 октября 2026; нового живого прогона магазинов не было. Подготовленная версия пакета 0.9.0 **не опубликована**. Изменение JSON само по себе не обновляет MCP-сервер и не открывает новые каталоги.

## Формат

`schemaVersion: 2` — версия реестра, а не плагина. `documentedPanelStoreCount: 17` соответствует длине `stores`. Старые ID сохранены; отдельных неподтверждённых записей `additionalNetworks` больше нет.

Каждая запись содержит `id`, `name`, `url` (официальную стартовую страницу), `skill` (путь относительно `references/` либо `null`), `officialDomains` (точные HTTPS-хосты, без масок поддоменов), `capabilities` и необязательную историческую проверку `historicalVerification`. Пути `evidence` относительны этому каталогу. История 25 октября не является новым наблюдением и не копируется в `checks`.

## Маршрут проверки

Границы задаёт запрос пользователя и явный выбор сетей панели. Пятёрочка показывается первой, но не выбирается автоматически. Если сети не заданы, уточнить охват в существующем чате, не запускать обход или сторонний каталог по умолчанию. Не подменять запрошенные 5ka + magnit поиском ВкусВилла.

В подготовленном контракте 0.9.0 новый вызов `prices_search` всегда получает `store_ids`; массив ограничивает и запросы к источникам, и результаты. `[]` не вызывает источники; отсутствие поля оставляет старое поведение для совместимости. На установленной 0.8.0 сначала проверить схему: если фильтра нет, не вызывать такой общий поиск для охвата, исключающего его источники. Явный каталог ВкусВилла использует прежний `products_search`.

Для четырёх импортируемых сетей без отдельного навыка использовать [общий сценарий](browser-workflow.md) и точные домены реестра. Бахетле использовать только через применимый подключённый источник, без `prices_browser_show`. CAPTCHA и исторические ошибки не являются постоянным запретом проверки: зафиксировать текущее препятствие, продолжить остальные сети и предложить [точечное продолжение](shopping-plan.md) после действия пользователя.

Список для магазина в панели не является оформленной корзиной на сайте. Ни навыки, ни реестр не подтверждают текущие цены, наличие, доставку или итог заказа. Итоги требуют свежих сопоставимых предложений в точном контексте; неизвестная доставка не бесплатна.
