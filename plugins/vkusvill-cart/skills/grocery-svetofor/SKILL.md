# Светофор: магазины и продукты

Идентификатор в панели и MCP: `svetofor`. Стартовая витрина: [Светофор](https://svetofor-rls.ru). Источник для проверки принадлежности: [сайт сети или группы](https://svetofor-rls.ru).

Перед работой прочитать [общий сценарий браузера](../grocery-prices-browser/references/browser-workflow.md). Для выгрузки использовать [формат наблюдений](../grocery-prices-browser/references/observations.md); для сравнения — [правила соответствия товаров](../grocery-prices-browser/references/matching.md).

## Особенности витрины

Региональный логист не представляет все магазины страны. Начать с региона и опубликованных магазинов, проверить принадлежность выбранной витрины оператору по реквизитам. Не использовать SEO-каталоги с названием «официальный» как доказательство. При отсутствии подтверждённого источника для города вернуть error с точной причиной; при официальном каталоге без цен — catalog_only. Региональный буклет не доказывает наличие в Казани. Новый региональный домен перед импортом требует подтверждения и добавления в серверный список; до этого вернуть ссылки в чате.

В прогоне 2026-10-25 svetofor-rls.ru показал логистический сайт со складами, включая Казань, без розничных карточек и цен. Склад не доказывает наличие магазина или товара. Результат catalog_only с пояснением; это не доказательство отсутствия сети в Казани.

## Результат

Для исследования магазина вернуть подтверждённые город, публичную точку/зону, режим получения и доступность каталога со ссылкой. Для поиска прочитать до трёх подходящих вариантов на позицию; открыть карточки, если выдачи недостаточно для фасовки, условий или состава. Для сравнения сохранить точный товар и допустимые замены раздельно. Не угадывать наличие по одной лишь отображаемой цене.

Передать наблюдения через `prices_browser_show` с `store="svetofor"`. Если сеть заблокирована или каталог недоступен, передать `checks` с наблюдаемой причиной. Сбой не означает, что сети нет в городе. При отсутствии инструмента вернуть связанную с источниками таблицу и локальный JSON без персональных данных.
