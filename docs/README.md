# Демонстрационный сайт

Статический сайт проекта для GitHub Pages: HTML, CSS и JavaScript без сборки, внешних библиотек, шрифтов и запросов к каталогу. Товары и цены в демо иллюстративные; заказ не создаётся.

## Локальный просмотр

Из корня репозитория:

```sh
python3 -m http.server 4173 --directory docs
```

Откройте `http://localhost:4173`.

## Публикация

В GitHub откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**. Workflow `.github/workflows/pages.yml` публикует только `docs/` после изменений в `main`. Его также можно запустить вручную через **Actions → Deploy demo to GitHub Pages → Run workflow**.

Адрес сайта после успешного деплоя: https://tawerka111.github.io/vkusvill-codex-marketplace/.

## Проверка после изменений

- Проверьте три сценария, повторный запуск и быстрые переключения.
- Измените количество: сумма должна обновляться, фокус оставаться на кнопке.
- Откройте и закройте финальный экран кнопкой и Escape.
- Проверьте ширину 375 px, горизонтальную ориентацию и управление клавиатурой.
- Включите системное уменьшение движения: демо должно сразу показывать результат. Ручной переключатель также выключает анимации.

Движение использует только `transform` и `opacity`; таймеры завершаются при скрытии вкладки и уходе демо за пределы экрана. Постоянных циклов, видео, WebGL и обработчиков прокрутки нет.
